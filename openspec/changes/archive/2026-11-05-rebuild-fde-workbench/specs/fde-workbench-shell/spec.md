# Spec Delta

## Purpose

定义“交付工作台”作为 DSH Web 插件的外壳行为：可被公司插件市场安装、在左侧栏提供唯一入口、在主区域承载工作台页面，并只通过已认证的同源通道与宿主交换数据。

## ADDED Requirements

### Requirement: 左侧栏入口与主区域面板

插件 SHALL 在左侧栏注册一个图标入口，并在主区域注册一个与之同键的面板；点击入口 SHALL 打开该面板，且面板在未选中时不渲染。

#### Scenario: 安装后从侧栏打开工作台

- **WHEN** 插件在 web profile 中启用并刷新页面
- **THEN** 左侧栏出现“交付工作台”图标，位于插件与定时任务入口之后
- **AND** 点击该图标后主区域显示工作台页面，且该图标进入选中态

#### Scenario: 面板键不一致时拒绝注册

- **WHEN** 实现把主区域面板的 key 与侧栏入口的 id 写成不同的值
- **THEN** 面板无法被侧栏选中，插件启动应视为失败并记录明确错误，而不是留下一个不可达的入口

### Requirement: 市场插件包形态

插件 SHALL 以包含宿主半与客户端半的 bundle 形式发布，具备市场索引所需的名称、版本、`engines.dsh`、locale 文案、图标与 README，并登记在仓库目录中。

#### Scenario: 静态索引包含工作台

- **WHEN** 维护者在 `catalog.json` 中登记该插件并运行静态索引构建
- **THEN** 生成的索引包含 `@acme-community/fde-workbench` 的条目，标题、描述、分类与图标均可读
- **AND** 安装来源指向 `plugins/fde-workbench`

#### Scenario: 缺少宿主入口时构建失败

- **WHEN** 插件包缺少 `dsh.bundle.patch` 或 `cordis.patch.yml` 不可读
- **THEN** 索引构建报告该插件被跳过及原因，而不是生成一个无法安装的条目

### Requirement: 已认证的同源数据通道

工作台的全部宿主接口 SHALL 挂载在 DSH 已认证的 `/api` 通道下的专用前缀，只接受 owner 主体的同源请求；插件 MUST NOT 提供任何绕过认证的 HTTP 路由。

#### Scenario: 未认证请求被拒绝

- **WHEN** 未携带有效浏览器会话的客户端请求工作台接口
- **THEN** 宿主返回 401，且不读取或返回任何工作台数据

#### Scenario: 跨站请求被拒绝

- **WHEN** 请求的 Host 或 Origin 不属于当前监听器或可信来源
- **THEN** 宿主返回 403，且不执行业务处理

#### Scenario: 插件卸载后接口消失

- **WHEN** 插件被禁用或其 Cordis 生命周期结束
- **THEN** 先前注册的工作台接口返回 404，侧栏入口与面板一并消失

### Requirement: 数据根目录与启动自检

插件 SHALL 使用一个可配置的绝对数据根目录，未配置时默认位于 DSH 主目录下；启动时 SHALL 创建缺失目录并写入供 agent 阅读的说明文件，不可写时 SHALL 以可见错误降级而不影响其他插件。

#### Scenario: 首次启用创建目录

- **WHEN** 配置的根目录尚不存在且父目录可写
- **THEN** 插件创建该目录与 `AGENTS.md`，面板显示空工作台而不是报错

#### Scenario: 根目录不可写

- **WHEN** 根目录指向只读位置或无法创建
- **THEN** 面板显示可读错误与修复建议，数据写入与 AI 操作被禁用，但插件仍能被禁用或重新配置

### Requirement: 多语言界面

插件 SHALL 通过 DSH 的 Client locale 服务提供简体中文与英文文案，覆盖全部静态界面文本；用户录入的内容 MUST NOT 随语言切换而改变。

#### Scenario: 切换语言

- **WHEN** 用户在 DSH 设置中把界面语言从中文切换为英文
- **THEN** 导航、按钮、空态、状态与提示文案变为英文
- **AND** 项目名、纪要原文、调研正文等用户内容保持原样

#### Scenario: 缺少翻译键

- **WHEN** 界面引用了字典中不存在的文案键
- **THEN** 冒烟测试失败并指出缺失的键，而不是在页面上显示空白

### Requirement: 插件生命周期收尾

插件 SHALL 在自身释放时移除路由、样式与槽位贡献，并在当前面板属于自己时把主区域交回会话。

#### Scenario: 使用中禁用插件

- **WHEN** 用户在工作台面板打开时禁用该插件
- **THEN** 主区域回到会话，侧栏入口消失，且没有残留的工作台样式或未释放的监听器
